# 他行ポイント施策ベンチマークと打ち手カタログ

ロイヤルティ顧客育成ロードマップの各クラスターを動かす手段は、実務上ほぼポイントキャンペーンに集約される。
本書は、ポイント戦略に長けた銀行の施策を調査して**6つの型**に整理し、
ななポ（77ポイントサービス）との差分を特定したうえで、
クラスター・育成ルートに紐づく**18本の打ち手カタログ**として提示する。

- 対象ダッシュボード: `dashboard.html` /「育成 › 施策ライブラリ」
- 関連文書: `docs/dashboard-requirements.md`（要件・クラスター定義・育成ルート）

## 2. 他行施策の6つの型

### 型1 ステージ（段位）型 — 取引の広がりに段位をつける

| 銀行 | 仕組み |
| --- | --- |
| 楽天銀行 ハッピープログラム | ベーシック／アドバンスト／プレミアム／VIP／スーパーVIP の**5段階**。最上位で ATM入出金無料 月7回・他行振込無料 月3回 |
| 住信SBIネット銀行 スマートプログラム | スマプロランクに応じ ATM・他行振込の無料回数が**最大15回** |
| 千葉銀行 ちばぎん ひまわり宣言 | 取引**項目数**に応じてブロンズ／シルバー／ゴールドの3ステージ |
| 福岡銀行 mybank+ | ステージプログラム＋マイコインプログラム（myCoin →地域特産品・他社ポイント・キャッシュバック） |
| 肥後銀行 ひぎんポイントサービス | ステップ制 |

**設計上の含意**: 判定軸を「残高」ではなく**取引項目数**に置く行が多い。
これは「広がり（クロスセル）」を直接報いる設計で、本ダッシュボードの横軸＝取引の広がりスコアと同じ思想である。

### 型2 常時付与（行動連動）型 — 行動そのものに値札をつける

| 銀行 | 仕組み |
| --- | --- |
| 三菱UFJ銀行 メインバンク プラス | 2021年に**ステージ判定を廃止**し取引ごとの付与に一本化。ダイレクトへのログイン 5Ponta/月、口座振替・カード引落 10Ponta/月、投信つみたて・外貨つみたて 1万円ごと 30Ponta/月。対象取引1回につき最大50ポイント |
| スルガ銀行 Gポイントクラブ | 給与をGポイントクラブ口座で受け取るだけで毎月 50Gポイント |

**設計上の含意**: 単価は 5〜50pt と極小。原資で買っているのではなく、
**「この行動にはポイントが付く」という事実を毎月可視化し続けること**そのものが効いている。
ななポには「アプリを開く」「口座振替を増やす」といった行動への値札が存在しない。

### 型3 残高連動型 — ストックに報いる

| 銀行 | 仕組み |
| --- | --- |
| 三井住友銀行 Olive | 口座残高を増やすほどVポイント。Vポイントアッププログラムは最大20%、1カードあたり月50,000ptが上限。NISA残高で+1%、条件により最大+2% |
| 住信SBIネット銀行 | 月末円普通預金残高200万円以上 → **翌月の**デビット還元率が最大2.0%（上限10,000pt） |
| 楽天証券 | 投信残高が初めて基準額に到達した時点で付与（初到達ボーナス） |

**設計上の含意**: ななポは配点の **94.7%（2,080/2,195pt）がこの型**で、他行より重い。
ただし他行は「残高そのものにポイント」で終わらせず、
**残高を条件に、次の行動（デビット利用）の還元率を上げる**という二段構えにしている。
残高は施策で動かしにくいが、還元率アップは行動を動かせる。ここが最大の差分である。

### 型4 切替イベント（メインバンク化）型 — スイッチングコストを買い取る

| 銀行 | 仕組み |
| --- | --- |
| 楽天銀行 | 公的年金受取で普通預金金利 最大+0.03%、年金受取1回ごとに1pt |
| イオン銀行 | 年金受取口座に指定 → 初回受取から**6カ月間**、条件達成で月200 WAON POINT |
| ゆうちょ銀行 | 年金受給開始から1年経過月の月末ごろ 1,000円を入金 |
| あおぞら銀行 BANK支店 | 給与・年金受取指定で**最大10万円が当たる抽選**（四半期ごと） |
| 東京スター銀行 | 1回5万円以上の給与振込・年金受取で毎月**抽選25名×25,000円** |
| JRE BANK | 給与・賞与・年金振込で 1,600pt |
| みずほ銀行 ご紹介プログラム | 紹介者・被紹介者の**双方**にみずほポイント1,000円相当 |
| スルガ銀行 | Gポイント付き口座振替サービス（公共料金の口座振替にポイント） |

**設計上の含意**: 切替は一度きりのイベントで、単価は 1,000円〜数万円相当と高い。
**抽選にして期待値を下げつつ見出しを大きくする**のが定番の解（最大10万円／25,000円×25名）。
ななポは給与・年金受取 各20pt のみで、切替イベントに事実上値札がついていない。

### 型5 ミッション／抽選（ゲーミフィケーション）型 — 頻度をつくる

| 事業者 | 仕組み |
| --- | --- |
| 楽天銀行 | アプリに1週間に1回・**合計3回**ログインで抽選300名×500円。**ログイン回数が増えるほど応募口数が増える** |
| 三井住友銀行「はじめよう＆おかえりキャンペーン」 | エントリー後アプリログインで条件達成（**休眠復帰**狙い） |
| 楽天Edy | 複数ミッションから**1つ以上**達成で150pt |
| 西日本シティ銀行 | デジタルギフトを景品にしたアプリ利用者獲得キャンペーン |

**設計上の含意**: 単価が低く、起動・ログインといった**頻度**を作るのに向く。
「1つ以上達成」「回数に応じて口数増」など、**達成のハードルを下げつつ上限を開けておく**構造が共通する。

### 型6 資産形成誘導型 — 一過性の申込を買わない

| 事業者 | 仕組み |
| --- | --- |
| りそな銀行「夏のつみたてスタート＆増額キャンペーン」 | NISA投信つみたての**開始または増額**が条件 |
| 京都銀行 NISAキャンペーン | 会員登録を条件にポイント付与。付与ポイントに**有効期限**を設定 |
| マネックス証券 | NISA投信つみたてを**3ヶ月連続**で継続した人を対象に抽選 |
| イオン銀行「NISAデビュー応援プラン」 | NISA開始を支援 |

**設計上の含意**: 条件が「開始」ではなく「**3ヶ月連続**」「増額」に置かれている。
申込だけして翌月止める顧客に原資を払わないための設計。

## 3. 全型に共通する設計文法（6点）

1. **エントリー必須** — 予算の上限管理と、参加意思（＝統制群を作れるデータ）の獲得を同時に行う
2. **付与上限の明示** — 月10,000pt／1カード50,000pt など、原資を先に確定させる
3. **継続を条件にする** — 3ヶ月連続・6ヶ月間毎月。単発の申込だけを買わない
4. **抽選の活用** — 期待値を下げたまま見出し訴求を大きくする
5. **有効期限付きポイント** — 付与時点で利用期限を切り、利用率を強制的に動かす
6. **ステージ判定は取引項目数** — 残高ではなく広がりで判定する行が多い

このうち **1（エントリー）は効果測定の前提でもある**。
エントリーの有無で参加者・非参加者が分かれるため、傾向スコアマッチングの共変量として使え、
DiD（`docs/dashboard-requirements.md` §7 Lv3）の推定精度が上がる。

## 4. ななポとのギャップ

| 型 | 他行 | ななポの現状 | 判定 |
| --- | --- | --- | --- |
| 型1 ステージ | 5段階・3段階が主流 | ダッシュボード上の内部区分のみ。**顧客に見える段位と特典差がない** | ギャップ大 |
| 型2 常時付与 | ログイン5pt/月など行動に値札 | **該当なし**（付与は取引結果に対してのみ） | ギャップ大 |
| 型3 残高連動 | 残高→還元率アップの二段構え | 配点の94.7%が残高・ローン残高。**一段目だけ** | 部分的 |
| 型4 切替イベント | 1,000円〜数万円相当＋抽選 | 給与・年金受取 各20pt のみ | ギャップ大 |
| 型5 ミッション／抽選 | 常設。休眠復帰にも使う | **該当なし** | ギャップ大 |
| 型6 資産形成誘導 | 3ヶ月連続・増額を条件 | 投資信託・NISA は付与対象外 | ギャップ大 |

**構造的な結論**: ななポは「**ストックの厚い顧客に報いる制度**」としてはよくできているが、
「**顧客を動かす制度**」の部品をほとんど持っていない。
これは §2 型3 で述べたとおり、残高は施策で動かしにくいため、
現状のななポは配点の 94.7% を「施策で動かせない変数」に置いていることを意味する。

この構造は、ダッシュボードの2軸モデルとも整合する。
横軸（取引の広がり）は残高だけでなく定期入金・決済・公共料金・資産形成を含み、
縦軸（デジタル接点）はアプリログを使う。**ななポの配点はこの2軸のうち一部しかカバーしていない**。

## 5. 打ち手カタログ（18本）

各打ち手は、ロードマップの育成ルート（R1〜R9）と対象クラスターに紐づく。
原資・反応率・昇格寄与率は他行の相場観からの**想定値**であり、実施後の実測で置き換える。

- **対象人数** = 対象クラスターの会員数（`dashboard.html` の CL データから算出）
- **原資** = 対象人数 × 反応率 × 単価
- **期待ロイヤルティアップ** = 対象人数 × 反応率 × 昇格寄与率
- **効率** = 原資 ÷ 期待ロイヤルティアップ（1人を上位クラスターへ動かす単価）

### 5.1 P01（ステージ制度）の扱い

効率だけを見れば P01 は最悪（21,250pt/人）で、単体では投資に値しない。
これは全会員に手数料優遇の原資がかかる一方、昇格寄与率が 0.8% と薄いためである。

しかし P01 は**他の17本の受け皿**として機能する。
- P02（取引項目数ボーナス）は段位がなければ「あと1項目で何が変わるのか」を訴求できない
- P07（残高条件つき還元率アップ）は段位に紐づけることで恒久施策として運用できる
- ミッション（P13）の報酬を「段位ポイント」にすれば、ポイント原資を使わずに動機づけできる

したがって **P01 は単独の打ち手ではなく基盤投資として評価する**。
効率ランキングからは除外し、導入判断は「17本の打ち手の実行可能性」を基準に行う。

### 5.2 原資規模の妥当性

| | pt | 円換算 | 現行比 |
| --- | ---: | ---: | ---: |
| 現行ななポ 年間付与 | 961.6百万pt | 9.62億円 | 100% |
| カタログ18本 合計 | 215.9百万pt | 2.16億円 | +22.5% |
| うちポイント原資（P01・P17 除く） | 96.9百万pt | 0.97億円 | **+10.1%** |

P01 の手数料優遇（119.0百万pt相当）はポイント原資ではなく手数料収入の逸失であり、
別枠で評価する必要がある。純粋なポイント原資の増分は **年 +10.1%** に収まる。

DiD（Lv3）で推定した会員1人あたり年間増分収益 4,400円 を用いると、
新規昇格 65,383人（P01 除く）× 4,400円 ＝ **2.88億円** の増分収益に対し、
ポイント原資 0.97億円 → **ROI 3.0倍**。現行プログラム全体の ROI 3.2倍とほぼ同水準となる。

## 7. 導入ステップ（12ヶ月）

### フェーズ1（0〜3ヶ月）— 計測の土台と低単価施策

| 打ち手 | 理由 |
| --- | --- |
| P17 期限付きポイントの利用喚起 | 新規原資ゼロ。未利用ポイント残高18.42億円という負債を動かす |
| P12 連続ログイン抽選 | 単価15pt。ミッション運用の型を小さく試す |
| P03 アプリ月次ログインポイント | 三菱UFJ型。接点スコアの底上げに直接効く |
| — エントリー機構の実装 | **フェーズ2以降の全施策の前提**。効果測定の統制群もここで作る |

### フェーズ2（3〜6ヶ月）— 取引の広がりを厚くする

P02 取引項目数ボーナス ／ P04 口座振替ポイント ／ P10 公共料金おまとめ ／ P13 月替わりミッション ／ P14 休眠復帰

フェーズ1でエントリー機構が動いていることが前提。ここから DiD による効果測定を本格化する。

### フェーズ3（6〜12ヶ月）— 高単価・制度変更をともなうもの

P01 ステージ制度 ／ P07 残高条件つき還元率アップ ／ P08 給与振込 ／ P09 年金受取 ／ P11 紹介 ／ P15 アプリ獲得 ／ P16 NISA ／ P18 資産形成デビュー ／ P05 つみたて額連動

## 8. 制度設計上の論点（実施前に確認すべきこと）

| 論点 | 内容 |
| --- | --- |
| 原資上限 | 他行は月・カード単位で上限を明示している。ななポにも打ち手ごとの上限を設ける |
| 有効期限 | P17 は既存残高が対象だが、新規付与にも期限を設けるかは会計上の負債計上と併せて判断する |
| 景品表示法 | 抽選型（P11、P12 の景品）は総付景品・懸賞の限度額規制の対象になりうる。取引額との関係を法務で確認 |
| 金融商品取引法 | P05・P16・P18 は投資勧誘に該当しうる。ポイント付与を勧誘の一部とみなすかを確認 |
| ホールドアウト | P15・P11 は対象母数が50万人と大きい。効果測定のため一部を非配信で残す |
| 個人データの利用 | クラスター判定・配信対象抽出に用いる項目の利用目的を、現行のプライバシーポリシーの範囲で確認する |
| 他社ポイント連携 | 福岡銀行 myCoin のように他社ポイントへ交換できると訴求力が上がる。交換先の追加は §6.6 交換・パートナー画面で効果を測る |
